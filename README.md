# MD Workstation

ナレッジの Markdown（Workstation とは別のフォルダ）を GitHub の非公開リポジトリに置き、
そこから「やること」「予定」「今日のノート」を見て、チェック・追加・編集するアプリです。

```
DataStore/
├── app/        画面（PWA。スマホ・ブラウザ用。Mac 版もこれをそのまま使う）
│   ├── src/    app.js のもと（タブごとのファイル）。直すのはここ → npm run build
│   └── app.js  src をつなげて作ったもの（直接は直さない）
├── mac/        Mac 版（Electron）。ローカルのフォルダを直接読み書きし、git で自動同期
├── tests/      テスト（unit：計算／e2e：画面／electron：Mac 版の画面）
└── scripts/    build・check・テスト用のサーバー
```

## 開発

```bash
npm ci
npm run build      # app/src → app/app.js
npm test           # まとめてテスト（push すると GitHub Actions でも流れる）
npm run serve      # http://localhost:8765/ で画面を見る
```

くわしい決まりは `CLAUDE.md`。

| | スマホ（PWA） | Mac 版 |
|---|---|---|
| ノートの場所 | GitHub（API で読み書き） | 手元のフォルダ（git のリポジトリ） |
| 変えたとき | その場で commit | 少しあとでまとめて commit・push |
| GitHub の変更 | 開いたとき・同期ボタン | 開いたとき・5分ごと・同期ボタンで pull |
| ほかのエディタの変更 | — | すぐ画面に出て、20秒後に commit・push |

- 画面の部品・色・アイコンは **Workstation モバイル**（`style.css` `icons.js`）と同じ
- PC・タブレットの幅（幅 700px 以上・高さ 500px 以上・Mac 版）では **旧 Workstation（Mac 版）と同じ並び・同じ部品**（タスクの行・追加欄・ダッシュボードの行・ガントの表・ノートのカードとフォルダの木は旧 Workstation の CSS をそのまま使用）。並び（左端のレール｜サイドバー｜ツールバー付きの中央。`desk.css`）：ダッシュボード、プロジェクトのページ（数字4つ＋2列）、カレンダー（月とその日を横に）、ノートを並べて書く画面（左に書く・右に見た目）
- PC・タブレットの幅のノートのタブは、旧 Workstation のノートの画面そのもの（`app/ws/`）。書く／並べる／読む・分割・全文検索・名前変更（リンクも書きかえ）・フォルダ・画像
- カレンダーで予定を入れる：
  - その日の欄に1行で書く（例：`14時 MTG`、`明日 10:00-11:30 歯医者`、`11/20 9時半 健康診断`、`金曜 19時〜21時 飲み会`、`来週の月曜 10:00 朝会`）。日付を書かなければ選んでいる日
  - 1日の時間割の空いているところを押す（マウスはドラッグで長さも）
  - 月のカレンダーで選んでいる日をもう一度押す、上の「予定を追加」
  - くわしい入力では、長さのボタン（30分〜3時間）と、前に入れたタイトルの候補が使えます
- ノートの見た目は **Mac 版のノート**と同じ（marked の拡張：`[[リンク]]`・`==ハイライト==`・`#タグ`・`%%コメント%%`、コールアウト、プロパティ、Roboto Mono ＋ Zen Kaku Gothic New）
- お金のカレンダー：日ごとに使った額（家計のデータ・ノートの 💸）と出費の予定を出す。予定はやることの行に `- [ ] 💸 68,000 家賃 📅 2026-11-25`（「出費の予定」ボタンで Inbox.md に書く）。押すと金額・名前・日にち・カテゴリを直せる・消せる。払ったらチェック。ホームにも「出費の予定」（期日すぎ＋これから30日）
- 毎日確認（旧 Workstation と同じ画面）：項目と休みの日は `Notes/毎日確認.md`（表と「## 休みの日」）、チェックはその日のデイリーノートの先頭のプロパティ（例 `運動: 1`、外すと 0）。今日のリング・連続日数・月の達成率・週のチェック表・18週間のカレンダー・休みの日。ホームに「今日の毎日確認」
- 気分：その日のノート（`YYYY/MM/DD/` のどのノートでも）に `- 気分 4/5 ひとこと`（1〜5、1日に何回でも・平均で見る）。ホームの顔を押す・ヘルスの「気分を書く」・TEDDY のどれで書いても同じ。ヘルスに線グラフ・睡眠や筋トレとのくらべ
- ヘルスのタブ：体重（デイリーノートの `- 体重 70.5kg`・7日平均・目標まで）、睡眠・歩数・心拍（`Data/health/health.csv`）、睡眠の質（1晩の流れ：`Data/health/sleep.csv` から、何時にレム・ノンレム・深いだったか／大きいグラフ：深い・コア・レム・途中で起きた の内訳／寝た〜起きた時刻、1晩の点数の目安）、筋トレ（`Data/kintore/sets.csv`。種目ごとの推定1RM・週の総挙上量）。「体重を書く」で今日のデイリーの「メモ」に入れる。目標はノートの先頭の `goal_weight`・`goal_due`
- デイリーノートは **Obsidian の `.obsidian/daily-notes.json`**（フォルダ・日付の書式・テンプレート）に合わせる（Mac 版と同じ計算 `daily.js`）
- 「やることを足す」は Mac のダッシュボードの「今日のノート」と同じ順で入れる（空の `- [ ]` → 最後のチェックリストの下 → 「やること」の見出しの下 → 最後）

## Mac 版

```bash
cd mac
npm install
npm start          # app/ をコピーして起動
npm test           # フォルダの読み書きと git の同期のテスト
npm run dist       # .dmg を作る（dist/ に出ます）
```

1. 「同期」タブで、ナレッジのフォルダを選ぶ
2. そのフォルダが git のリポジトリで `origin`（GitHub の非公開リポジトリ）があれば、自動で同期します（「自動で同期する」でオフにもできます）
3. GitHub への push は、ふだんターミナルで使っている git の設定（SSH の鍵や認証）をそのまま使います

- 同じ行を Mac と GitHub の両方で書きかえて取り込めなかったときは、上書きせずに「同期」タブに知らせます。そのときはターミナルで `git pull` して直してください
- `.obsidian/daily-notes.json` がなければ、`2026-11-10.md` のような名前のノートがいちばん多いフォルダをデイリーノートの場所にします

## スマホ（PWA）の使い方

1. GitHub に**非公開**のリポジトリを作り、ナレッジのフォルダを push する（Mac 版を使うならそのフォルダが手元のリポジトリになる）
2. `app/` の中身を**公開**リポジトリに置き、Settings → Pages で公開（アプリのコードだけなので、公開してもノートは見えません）
3. GitHub → Settings → Developer settings → Fine-grained tokens で、そのリポジトリだけ・**Contents：Read and write** のトークンを作る
4. アプリの「同期」タブに、オーナー・リポジトリ・トークン（ノートがリポジトリの中のフォルダなら「読むフォルダ」も）を入れる

トークンは端末の中（localStorage）にだけ保存し、GitHub 以外へは送りません。

## ノートの置き方（日付フォルダ＋タグ）

- その日に書くノートは `2026/11/10/` のような**その日のフォルダ**に、何個でも置けます。そのフォルダの中のノートは全部「その日の分」になります（ホームの「今日のノート」・カレンダー・ノートの「日付ごと」）
- その日のやること・予定は `2026/11/10/デイリー.md`。「やることを足す」はここに入ります（`.obsidian/daily-notes.json` の `"format": "YYYY/MM/DD/[デイリー]"`。設定がなくても日付フォルダを見つければこの形にします）
- カテゴリはフォルダではなく**タグ**：先頭の `tags: [仕事, java]` か本文の `#タグ`。「ノート」でタグを押すとそのカテゴリだけ出ます。新しいノートを作るときにタグを付けられます

## 書き方

| 書き方 | 意味 |
|---|---|
| `- [ ] やること` | やること。デイリーノートに書くとその日の分 |
| `@due(2026-11-20)` / `📅 2026-11-20` / `@2026-11-20` | 期限 |
| `- 14:00 MTG` / `- 10:00-12:00 面談` | 予定（デイリーノートや `## 2026-11-20` の見出しの下） |
| `- [ ] 18:30 ジム` | 時刻つきのやること（今日の予定にも出ます） |
| `#タグ` | やることの絞り込み |

### プロジェクト（Workstation のプロジェクトと同じ項目）

`Projects/`（または `プロジェクト/`）のノート1つが、1つのプロジェクトです（ほかの場所でも、先頭に `type: project` と書けばプロジェクト）。

```markdown
---
color: "#005cff"
links:
  - GitLab https://gitlab.com/...
  - 設計書 https://...
---
Spring Boot のグループ開発。（← 最初の見出しまでが「メモ」）

## タスク
- [ ] 画面設計 🛫 2026-11-10 📅 2026-11-14
- [ ] 発表 📅 2026-11-28 #節目
```

| 書き方 | 意味 |
|---|---|
| `🛫 2026-11-10` / `@start(2026-11-10)` | 開始日（ガントのバーの左はし） |
| `📅 2026-11-14` | 期限（バーの右はし） |
| `#節目` / `🏁` | 締切・発表日などの節目（ガントでは丸） |
| ほかのノートで `- [ ] API修正 [[ほのぼの書店]]` | そのプロジェクトのタスクになる |

「プロジェクト」タブ：一覧（進み具合・次の期限）、プロジェクトの中（タスク・メモ・リンク・タスクを足す）、ガントチャート（Workstation モバイルと同じ形）。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` | 画面（Workstation モバイルの CSS ＋ Mac 版のノートの CSS） |
| `desk.css` | PC の幅の並び（Mac 版 Workstation のレール・サイドバー・ダッシュボード・プロジェクトのページと同じ値） |
| `app.js` | 画面の動き・GitHub との読み書き |
| `parser.js` | Markdown からやること・予定を取り出す／チェックの切り替え／やることを足す |
| `daily.js` | デイリーノートの場所と日付（Mac 版 `src/main/notes.js` と同じ） |
| `icons.js` | Lucide アイコン（Workstation と同じ＋いくつか追加） |
| `vendor/` | marked・DOMPurify・フォント（Mac 版と同じもの） |
| `sw.js` / `manifest.webmanifest` / `icons/` | PWA の設定。ファイルを変えたら `sw.js` の `VERSION` を上げる |
| `mac/main.js` / `mac/preload.js` | Mac 版のウィンドウ・画面とのやりとり（preload が `window.mdws` を用意すると、app.js はローカルのフォルダを使う） |
| `mac/backend.js` | フォルダの .md の読み書きと git（pull / commit / push）。Electron なしでテストできる |
